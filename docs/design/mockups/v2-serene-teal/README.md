# v2 "Serene Teal"

The first proposal: an evolution of the current SereneMed design system.

- **Palette:** cool grey canvas `#f4f7f7`, white surfaces, deep teal shell `#0c3d3e`, one accent teal `#12706f` (light mint `#7fd4cc` on dark).
- **Type:** Geist + Geist Mono for staff; Atkinson Hyperlegible Next for patients (17px base).
- **Shape:** 12px panels, 8px controls, soft card shadows.
- **Navigation:** deep-teal collapsible sidebar with clinic switcher (Fireact pattern), quiet top bar with breadcrumbs and ⌘K; patient bottom tabs.
- **Signature components:** bento "Ready for you" card on Today; three-column consultation with a sticky finish bar; live visit tracker on patient Home.

**Why:** closest to what is built today, so the cheapest to adopt, and the teal brand carries through.
